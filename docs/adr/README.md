# Registro de decisiones (ADR)

Cada decisión con consecuencias se registra en un ADR: un fichero corto con el contexto, la
decisión, las alternativas descartadas y sus consecuencias. Los ADR no se editan una vez aceptados:
si la decisión cambia, se escribe uno nuevo que sustituye al anterior. La skill
[adr](../../.claude/skills/adr/SKILL.md) describe el formato.
