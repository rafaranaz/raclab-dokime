+At least for now, the implementation prefers clarity and performance

+        try:

+

+            try:

+            except KeyError:

Comparing a `Version` with a `dict`, `tuple`, or `list` that cannot construct a
valid version (for example, an empty collection, wrong number of parts,
non-numeric parts, or unknown keys) no longer raises internal errors
from `Version.__init__`.

The comparison operators now return `NotImplemented` for such operands,
following the general rule for invalid comparison operand types: equality
evaluates to `False` and ordering raises Python's standard `TypeError`
(for example, `>` not supported between instances of 'Version' and 'dict'`).

+    # equality must evaluate to False, not raise an internal error
+    # such as "Version.__init__() missing 1 required positional
+    # argument: 'major'".

+    assert (other == version) is False
